# SHECARES

This project is a web application designed to provide various services for women's health and safety.

## Features

- Period tracking
- Pregnancy care
- Food analysis
- Mental wellness support
- Emergency safety features
- Connection with doctors and caretakers

## Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Python, Flask

## Getting Started

### Prerequisites

- Node.js and npm
- Python and pip

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/pixelcrisscross/SHECARES.git
    cd SHECARES
    ```

2.  **Install frontend dependencies:**
    ```bash
    cd frontend
    npm install
    ```

3.  **Install backend dependencies:**
    ```bash
    cd ../backend
    pip install -r requirements.txt
    ```

### Running the application

1.  **Start the frontend development server:**
    ```bash
    cd frontend
    npm run dev
    ```

2.  **Start the backend server:**
    ```bash
    cd ../backend
    python main.py
    ```
